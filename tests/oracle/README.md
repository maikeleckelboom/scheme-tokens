# Published 0.3.0 oracle

`published-0.3.0.json` was generated by `scripts/generate-v1-oracle.ts` from the npm registry tarball for `scheme-tokens@0.3.0`. The generator verifies both the registry SHA-512 integrity and SHA-1 shasum before it imports the extracted package. Regeneration requires an explicit tarball path; routine tests never download or execute the old package.

The representative records keep the complete published v1 serialized graph and compiled results, including origin, dependencies, visibility, metadata, mode order, and public selection. The 2,000 generated cases use fixed fast-check seed `0x40302026`. The fixture stores one digest per published output plus a digest of all generated inputs. This keeps the corpus reviewable and compact while making accidental generator drift fail. The shared projection in `scripts/v1-oracle-evidence.ts` compares values, effective visibility, descriptions, deprecation, and extensions; v1 origin and dependency record shapes are intentionally limited to the representative evidence because v2 changes those shapes.

At P2, feed each generated v1 input through the v1-to-v2 upgrader, compile it, construct the same comparable projection from the v2 result, and compare its digest to the frozen published digest. Do not regenerate the expected digests from the current source package.
